# Task 25 - Concatenating DataFrames

## Overview
This task demonstrates how to combine DataFrames using Pandas concatenation.

## Topics Covered
- Vertical concatenation
- Horizontal concatenation
- Resetting indexes
- Concatenation using keys
- Combining DataFrames with different columns

- Concatenating multiple DataFrames
- Sorting column names
- Concatenating selected columns

## Tools Used
- Python
- Pandas
- Jupyter Notebook
